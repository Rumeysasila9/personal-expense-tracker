# Personal Expense Tracker

## Description 

This project is a simple expense tracker built with Python, created to practice core Python concepts and develop a functional command-line application.


## Features 


- Enter a monthly budget
- Add expenses
- View expenses
- Calculate total expenses
- View the number of expenses
- Delete an expense
- View the remaining budget
- Exit the program 


## Technologies

- Python 
- Git
- GitHub


## How to Run

1. Clone this repository:
   
   ```bash
   git clone https://github.com/Rumeysasila9/personal-expense-tracker.git 
   ```
2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the program:     

   ```bash
   python personal_expense_tracker.py
   ```
